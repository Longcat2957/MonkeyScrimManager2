## Direction contract

**범위:** 외부 Discord 서버 운영자 대상 로컬 체험. 소개 화면은 상단 내비를 사용하고 운영 도구의 사이드바와 분리한다. 실제 설치·Discord 명령·업무 저장은 하지 않으며 운영 루트의 서버 선택 및 로그인 후 진입을 유지한다.

**THESIS:** ‘두 화면, 한 내전’을 조작으로 증명한다. 꾸민 모집 글과 정적 점수판 대신 실제 내 신청, 미배정 목록, 팀 카드와 경기 상세 화면을 사용한다.

**OWN-WORLD:** Rift 표면과 가는 구분선, 시안 동작 한 개, 양 진영 색, 고정폭 숫자. 워드마크는 Oxanium, 한국어는 Noto Sans KR. 기존 셸과 푸터의 조작을 중복하지 않는다.

**STORY:** 방문자가 가상 내전의 열 번째 참가자로 신청하고 참가 정보를 바꾼다. 편성에서 자신의 자리를 선택하고 다른 선수와 교환하거나 배정을 해제한다. 이전 경기 예시는 별도로 열어 선수 상세를 확인한다. 편성만으로 승패나 MMR이 생기지 않는다.

**FIRST VIEWPORT:** 워드마크·체험·사용법·앱 진입은 상단 내비 한 곳에 둔다. 헤드라인 아래 참가 신청과 팀 편성을 나란히 놓고 좁은 화면에서는 조작 순서대로 쌓는다. 새로고침은 초기 명단으로 돌아간다. 키보드와 터치로 같은 작업을 끝낼 수 있어야 한다.

**FORM:** 사용자 선택 ‘두 화면, 한 내전’(6번째 구조), seed:40acba6d48ca54fc.

**검증:** 1440px와 390px에서 상단 탐색, 앱 진입·뒤로 가기, 참가 수정·철회, 키보드 배치·교환, 선수 상세를 확인했다. 체험 중 POST 요청은 없었다. 운영 빌드에서는 소개 경로가 404이고 기존 홈 진입은 유지된다.
