# 전적과 통계 조회

현재 소비자는 `/g/[guildId]/players/[userId]`, `/stats`다.
경기 상세와 같은 채택 Game·당시 실출전 기록을 원천으로 사용한다. 시즌 순위는 `guild/`와 `mmr/`의 유효 반영 자료를 사용한다.

`queries.ts`는 개인 전적·서버 통계·현재 시즌 MMR 조회(R)를 담당한다.
현재 페이지·필터 계약과 지표별 집계 범위를 유지하고, 필요한 SQL 집계와 기존 순수 계산 함수를 사용한다.
조회 전용 기능이므로 별도 `service.ts`나 전적 CRUD API를 미리 만들지 않는다.

MSM1과 같이 전적·통계의 기본 범위는 현재 활성 시즌이다. 활성 시즌이 없으면 빈 전적을 반환한다.
과거 시즌을 선택하는 조회 입력·화면은 아직 없다. 현재 시즌의 Game·실출전을 읽어 순수 계산 함수에서 집계한다.
개인 전적도 같은 포지션의 다른 사용자와 비교하기 위해 현재 시즌의 서버 전체 기록을 유지한다.
출전자는 Game별로 한 번 묶어 재사용하며, 경기마다 전체 출전자를 다시 검색하지 않는다.
취소된 내전·대진의 게임은 제외하고, 중도 종료(`ended_early`) 전에 확정된 게임은 보존한다.
시즌과 실제 사용자가 확인되면 개인 MMR은 5개 포지션을 반환하며, 아직 점수가 없는 포지션은 초기값 1500·0경기다.
순위는 현재 서버 멤버 중 해당 시즌·포지션의 유효 반영 경기가 1개 이상인 사용자만 대상으로 한다.
순위 아이콘은 해당 시즌·실제 포지션에서 가장 많이 사용한 챔피언이며 동률은 챔피언 식별자 순이다.

사용자 귀속은 당시 출전 기록으로 고정한다. 현재 계정 소유자 변경으로 과거 기록을 바꾸지 않는다.
누락된 수치·포지션·날짜는 nullable로 반환하고 0·희망 포지션·업로드 시각으로 채우지 않는다.
유효 표본·분모를 지표별로 정하고 빈 데이터와 조회 실패를 구분한다. 목 평점·업적·통계는 합의된 평가 기준 없이 운영 계산으로 옮기지 않는다.
실제 업적은 표시하지 않는다. 경기 시각이 미확인인 기록이 섞이면 최근 기록·연승·연패를 추정하지 않는다.

상세 계약은 [백엔드 계획의 전적과 통계](../../../../../../docs/backend-plan.md#57-전적과-통계)를 따른다.
