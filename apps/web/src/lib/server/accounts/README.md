# 계정 연결

소비자는 `/me`의 본인 연결 계정 조회와 `/g/[guildId]/admin`의 `lookup`, `link`, `primary`, `unlink` action이다.
Riot 식별 행은 재사용하지만 사용자 연결·대표 여부·변경 권한은 서버별이다. 같은 계정도 서버마다 다른 사용자에게 연결될 수 있다.

구현 파일과 책임:

- `queries.ts`: 본인의 서버별 연결 계정·관리 대상 멤버 조회, 기존 `server/riot`을 통한 관리자 Riot 계정 조회(R).
- `service.ts`: 서버별 사용자와 Riot 계정 연결(C), 대표 계정 변경(U), 연결 해제(D). 실제 권한·대상 멤버·같은 서버의 연결 소유와 동시 변경을 검증한다.

연결 해제는 `guild_riot_accounts`의 해당 서버 연결만 삭제한다. 같은 서버의 활성 신청 사용 여부를 확인하고 다른 서버 연결·과거 출전·MMR 귀속을 보존한다.
계정 변경과 신청이 경합할 때 사용자·Riot 계정을 고정 순서로 먼저 잠그고 서버별 연결·내전을 잠근다. `/me`에 별도 수정 기능은 추가하지 않는다.

상세 계약은 [백엔드 계획의 계정 관리](../../../../../../docs/backend-plan.md#52-서버-관리와-계정-연결)를 따른다.
