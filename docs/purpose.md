# 프로젝트 목적

`MonkeyScrimManager2`(`MSM2`)는 [MSM1](https://github.com/Longcat2957/MonkeyScrimManager)의 리그 오브 레전드 내전 운영을 다시 구현한다. 사용자에게 표시하는 서비스명은 **Monkeybot**이다.

## 유지할 규칙과 바꿀 규칙

- 모집·편성·경매·대진·전적·MMR·정정은 MSM1의 실제 구현을 기본값으로 삼는다. 기존 코드 구조나 결함까지 재현하지 않는다.
- 일반 서버 화면은 공개한다. 조작할 때는 현재 Discord 서버의 소속과 권한을 검사한다. 참가에 웹 사전 가입이나 Riot 계정 연결을 요구하지 않는다.
- Discord 사용자는 서버마다 Riot 계정을 연결한다. 서버 내 표시 이름은 서버 별명, Discord 전역 표시 이름, 사용자명 순으로 사용한다.
- 서비스는 모집·팀 편성·대진·시리즈 라인업을 운영한다. 밴픽·픽 순서·경기 중 진행은 게임에 맡긴다.
- 수동 결과 입력을 ROFL 업로드로 대체한다. 서비스를 통해 확정한 경기·세트 번호·라인업에 파일의 실제 결과를 연결한다. 하드 피어리스 위반은 안내하되 등록을 막지 않는다.

## 기록과 개인정보

권한·계정 귀속·중복·데이터를 검증한 정상 파일은 별도 승인 없이 기록한다. 연결 근거가 없으면 실패로 처리한다. 배열 순서나 별명으로 출전자를 추정하지 않고, 알 수 없는 실제 경기 시각은 비워 둔다.

서비스는 파일 지문·크기·버전·업로더·등록 시각, 실제 출전과 선별 통계만 저장한다. 원본 ROFL·전체 메타데이터·패킷 덤프·보관 경로는 저장하지 않는다. 재분석하려면 원본을 다시 업로드한다. 개발자의 로컬 연구용 `samples/`는 Git과 운영 저장소에서 제외한다. 필드와 정정 규칙은 [ROFL 적재 계약](rofl-import.md)을 따른다.

탈퇴해도 과거 경기와 MMR의 내부 귀속은 보존한다. 공개 화면은 현재 개인정보 설정을 따르며 다른 사용자의 서버별 계정 연결은 삭제하지 않는다. 진행 중인 확정 출전을 훼손하는 탈퇴는 해당 참여가 정리될 때까지 제한한다.

## 구현 경계

`apps/web`은 SvelteKit 풀스택과 PostgreSQL·Drizzle을 사용한다. `apps/bot`은 Discord 입력·발송을 맡고 웹의 업무 서비스를 사용한다. 실제 소비자가 필요한 외부 API만 추가한다.

웹은 [Rift 디자인 기준](web/design-system.md)에 따라 자체 Svelte 컴포넌트, 네이티브 HTML, Tailwind CSS로 구현한다. 같은 기능과 설명은 한 화면에 한 번만 둔다.
