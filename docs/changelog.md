# 주요 변경 이력

현재 동작은 [웹 문서](web/README.md)와 [서버 구조](../apps/web/src/lib/server/README.md)를 따른다.

## 미배포

- Discord 대기 신청 시 한국 시각으로 도착 시각을 지정해 선발 자리를 예약할 수 있다. 모집 중 예약 시각이 지나면 자동 선발하며, 철회·제외·정원 증가로 생긴 빈자리는 자동 충원하지 않는다.
- 서버 통계 리더보드는 시즌 MMR 내림차순으로 고정하고 선수명 옆에 점수를 표시한다. 전체 포지션에서는 실제 반영된 포지션 중 최고 MMR을 쓴다.
- 이용약관과 개인정보 처리방침에 내전 운영·공개 전적·데이터 처리 및 권리 행사 기준을 명시했다.
- 경매 준비 화면의 `핀볼 추첨`을 갈림길과 경사로가 있는 장거리 레이스로 바꿨다. 기본 카메라는 출발 무리와 접전, 결승을 자동 중계한다. 미니맵으로 전체 코스를 보거나 특정 구슬을 직접 따라갈 수 있다. 설정 저장 전에는 다시 추첨할 수 있으며, 수동 팀장과 시작 포인트는 유지한다.
- 핀볼 창에서 이번 팀장 추첨에 참여하지 않을 사람을 먼저 고를 수 있다. 제외해도 내전 참가나 이후 경매에는 영향을 주지 않는다.
- 팀장 핀볼은 먼저 도착한 구슬이 아닌 마지막 도착자를 선발한다. 10명이 두 자리를 추첨하면 9·10번째 도착자가 팀장이 된다. 참가자 이름표는 작게 표시하고, 구슬이 서로 추월해도 이름표가 갑자기 자리를 바꾸지 않도록 했다. 구슬마다 자동 부스트가 한 번 발동한다.
- 모집 마감 후 선발된 참가자의 솔로랭크 정보를 백그라운드에서 갱신한다. 경매 후보 카드에서 현재 랭크·시즌 관측 최고와 최근 최대 20경기의 주력 챔피언을 확인할 수 있다.
- Riot가 생략한 LP·승패는 0으로 읽고 음수 LP는 그대로 표시한다. 랭크와 최근 경기는 독립적으로 재시도하며, 경기 조회가 중단되면 이미 받은 목록에서 이어간다.
- 취소·중도 종료된 내전을 복구하면 누락된 후보 전적을 다시 조회한다. 내전 시즌 전적이 없는 후보도 상세 보기에서 낙찰 이력을 확인할 수 있다.
- 본문 우상단 배경광이 마우스 위치에 부드럽게 반응한다. 터치와 동작 줄이기 설정에서는 움직이지 않는다.
- 서버 메뉴 이동 시 본문만 전환하고, 같은 내전의 단계 이동은 작업판과 단계 밑줄로 표시한다. 경매 낙찰·선수 배치·명부 변경·ROFL 등록은 바뀐 항목만 강조한다.
- ROFL을 등록하기 전에 같은 창에서 양 팀의 승패, 출전자별 계정·포지션·챔피언·K/D/A와 신규 연결을 확인한다. 미리보기만으로는 전적이나 점수가 바뀌지 않는다.
- Discord 새 모집도 웹처럼 시작 예정 시각을 30분 뒤로 채운다. 직접 지운 일정은 미정으로 저장한다.
- 개인 지표의 상위 비율에서 25명 중 7위가 `29%`로 올라가던 반올림 오차를 고쳤다. 팀 총 킬이 0이면 킬 관여율을 `0%` 대신 `—`로 표시한다.
- API 요청 로그에 세션·길드 접근·DB·Riot·Discord·Data Dragon·봇 호출 시간을 추가하고, `/metrics` Prometheus 메트릭과 Grafana API 성능 대시보드를 붙였다. 공개 `/metrics`는 404이며 Grafana는 `/grafana`에서 로그인 후 사용한다. 패널·PromQL·요청 로그 읽기 방법은 [모니터링 안내](monitoring.md)에 정리했다.
- 출전 라인업에서 포지션 행 전체에 선수를 놓을 수 있게 했다. 드래그 중에는 같은 팀에서 배치하거나 교환할 수 있는 자리를 표시한다.

## 2026-11-19

- 내전은 10인(2팀)과 20인(4팀)만 지원한다. 경매는 평균 낙찰가 순위가 높을수록 앞 순번에 호명될 확률이 선형으로 높다. 단독 1위가 처음 나올 확률은 각각 18%, 9%다. 서버 관리의 멤버별 경매 가격 설정은 제거했다.
- 경매 후보 목록에서 대기자를 추첨 없이 팀에 수동 배치할 수 있다. 진행 중인 다른 후보의 입찰은 유지되며 직전 배치를 되돌리면 원래 추첨 순서를 복원한다.

## 2026-11-18

- 웹을 Rift 시안 기준의 자체 Svelte 컴포넌트로 전환했다. 처음 방문하면 다크 모드로 열리고 저장된 테마는 유지한다.
- 서버 홈은 다음 내전과 현황을 먼저 보여 준다. 수동 편성과 경매는 기존 배치와 조작 순서를 유지하고 다른 화면과 같은 Rift 디자인을 사용한다.
- 경기 시작 전에 1세트 블루 팀을 지정하고 경기 상세에서 다음 세트 진영을 정할 수 있다. ROFL 업로드는 예정 진영을 미리 표시하되 실제 진영을 따로 확인한다.
- 수동 편성은 선수 배치부터 보여 주고 시작 설정은 팀 목록 뒤로 옮겼다. 대진은 경기별 배치를 먼저 보여 주며 경기 상세에서는 예정 진영을 조회하면서 필요할 때만 편집한다.
- 경매 대진에서는 팀을 1세트 블루·레드 자리에 바로 배치하거나 같은 경기 안에서 두 팀의 진영을 교환할 수 있다.
- 경매 후보를 수동 배치할 때 입찰가 입력칸과 금액 조절 버튼 위에서도 대상 팀 강조가 유지되도록 수정했다.
- 새 내전의 시작 예정 시각은 모집 만들기를 누른 시각보다 30분 뒤로 채우며, 저장 전에 변경할 수 있다.
- 서버 통계와 개인 전적에 경매 탭을 추가했다. 선수별 거래 가격을 비교하고 각 경매의 영입 순서와 예산을 복기할 수 있다. 개인 전적에서는 선수로 낙찰된 내역과 팀장으로 영입한 명단을 구분한다.
- 선수 사진은 Discord 전역 아바타로 통일했다. 공개 사용자가 커스텀 사진을 쓰지 않으면 Discord 기본 아바타를 표시하고, 공개 화면에서 비공개·탈퇴 사용자의 사진은 노출하지 않는다.
- 수동·경매 편성 완료 후에도 경기 시작 전에는 대진에서 편집을 다시 열 수 있다. 내전 배정과 경매 원장을 보존하며 2팀 수동 편성도 확정만으로 경기가 시작되지 않는다.
- 서버 메뉴에서 코인토스·사다리·룰렛을 열 수 있다. 동전이 뒤집히는 모습, 사다리의 이동 경로, 룰렛 지침이 당첨 칸에 멈추는 과정을 보여준다. 동작 줄이기 설정에서는 결과를 즉시 표시한다. 결과는 운영 데이터에 반영하지 않는다.

## 2026-11-05

- Riot 계정 확인 화면에서 조회한 계정만 연결하도록 했다.
- Discord 게시 복구 시 다른 종류의 글이 연결되지 않도록 작업 식별자를 확인한다.
- 하드 피어리스 안내는 같은 시리즈에서 양 팀이 사용한 챔피언을 합친다. 취소된 세트는 제외하고 결과 등록은 막지 않는다.

## 2026-11-02

- 신규 신청은 빈 선발 자리가 있으면 선발, 없으면 대기로 기록한다. 선발자가 빠지면 먼저 신청한 대기자부터 승급한다.
- 팀 이름을 자동 지정하고, 기록을 보존하는 중도 종료와 단계 되돌리기를 추가했다.
