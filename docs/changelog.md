# 변경 이력

## 2026-10-28

- 초기 상태에서 웹·봇 진입점과 패키지 설정이 없음을 확인.
- pnpm 워크스페이스 및 루트 실행·빌드·타입 검사 명령 추가.
- `apps/web`에 SvelteKit 3, Svelte 5, TypeScript 6 기반 최소 진입점 구성.
- 디자인 프레임워크로 STDF 3을 적용하고 Tailwind CSS 4와 기본 테마 연결.
- VPS 실행을 위한 Node 어댑터 및 운영 서버 시작 명령 추가.
- 봇과 데이터베이스 연결은 미구현 상태로 유지하고 README에 현재 범위 기록.
- 후속 결정에 따라 `apps/bot`에 discord.js 기반 TypeScript 진입점과 토큰 환경 변수 예제 추가.
- 봇 개발·빌드·운영 실행 명령을 추가하고 루트 검사·빌드에 봇 포함.
- 루트 레이아웃에 공통 헤더·본문 컨테이너를 구성하고 첫 페이지의 콘텐츠 영역 분리.
- 인증·권한 검사를 연결할 서버 훅의 최소 틀 추가. 실제 인증과 접근 정책은 미구현.
- MSM1의 실사용 favicon·로고를 원본 그대로 가져와 공통 HTML·헤더에 연결.
- STDF 단일 테마 규약에 맞춰 전역 그레이·슬레이트 색상과 라이트·다크 모드 토큰 설정.
- MSM1과 동일한 Google Fonts Noto Sans KR 로딩 설정과 전역 폰트 적용.
- 내부 프로젝트명 `MonkeyScrimManager2`와 사용자 표시명 `Monkeybot`을 구분하는 규칙을 AGENTS·목적 문서·README에 명시.
- 웹 표시명을 `SERVICE_NAME`으로 통합하고 화면·브라우저 제목에서 프로젝트명 노출 수정.
- 웹 표시명 규칙 검사 `check:branding`을 루트 `pnpm check`에 연결해 잘못된 표기와 직접 작성 방지.
- `Monkeybot` 워드마크에 Geist Pixel Square를 적용하고 본문·UI의 Noto Sans KR과 구분하는 규칙 추가.
- STDF 사이트를 참고해 64px sticky 헤더·반응형 내비게이션·모드 전환과 본문 좌우 경계선 구성.
- 공통 경계선 토큰을 추가해 라이트·다크 모드의 레이아웃 구조선 통일.
- 공통 푸터를 추가하고 본문과 폭·경계선을 공유하도록 정리. 짧은 페이지에서도 화면 하단에 푸터 표시.
- `Monkeybot` 워드마크의 `font-brand`를 Geist Pixel에서 Jersey 10 regular 400으로 교체.
- MSM1을 참고해 푸터를 서비스 도메인·문서·이용약관·개인정보 처리방침과 운영 문의 안내로 구성하고 기존 서비스 주소에 연결.
- 한 페이지의 기능 조작 지점과 설명을 중복하지 않는 웹 UI 규칙 및 완료 전 화면 전체 검토 기준 추가.
- 푸터의 운영 문의 문구와 내부 구분선을 제거하고 여백을 줄여 간결하게 정리.
