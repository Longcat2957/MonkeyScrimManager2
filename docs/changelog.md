# 변경 이력

## 2026-10-29

- Discord OAuth2 전용 로그인에 맞춰 `users` 스키마와 `User`·`NewUser` 타입 추가. Discord ID를 문자열 기본키로 사용하고 전역 프로필 및 생성·수정 시각을 저장.
- 첫 User 테이블 마이그레이션을 개발 DB에 적용하고 중복·필수값 제약, 프로필 null 처리, 생성·수정 시각을 검증한 뒤 테스트 데이터 롤백. Riot 계정 연결·세션·OAuth 로그인 처리는 후속 객체와 기능으로 유지.
- ROFL 적재 초안을 현재 공통 메타데이터·참가자 및 V1 경기·참가자 테이블의 삽입 행에 맞추고, 참가자 연결을 `scrimParticipantId`로 변경. 파일 보관 키·전체 파싱 결과 보관을 제거하고 UUID·중복 연결·버전 계약을 검증.
- 서비스의 원본 ROFL·전체 메타데이터 미보관 정책과 파일 재업로드가 필요한 재분석 조건을 문서화. 로컬 연구 도구는 별도 유지하고 README의 스키마 현황을 갱신. 이번 적재 모델 정리에서 DB 저장·마이그레이션 생성·적용은 수행하지 않음.
- 서비스 책임을 모집·팀 편성·경매·대진 운영과 ROFL 최종 결과 기록으로 명시. 밴픽·픽 순서 관리 테이블·관계·타입과 빈 밴픽 페이지를 제거하고, 적재 API를 `prepareRoflImport`·`RoflImportData`로 정리하며 승인 대기 상태를 제거. 정상 결과의 자동 등록과 예외 처리 원칙을 문서화했으며 실제 업로드·자동 연결·DB 저장은 후속 구현 범위로 유지.
- 실제 출전 기록의 ROFL 참가자 참조를 필수로 변경하고 역조회 복합 인덱스 추가. 경매 후보 상태와 종료 시각의 일관성 CHECK를 추가하고 전체 DB ERD 문서 작성. 스키마 정의만 변경하며 마이그레이션 생성·DB 적용은 수행하지 않음.

## 2026-10-28

- 초기 상태에서 웹·봇 진입점과 패키지 설정이 없음을 확인.
- pnpm 워크스페이스 및 루트 실행·빌드·타입 검사 명령 추가.
- `apps/web`에 SvelteKit 3, Svelte 5, TypeScript 6 기반 최소 진입점 구성.
- 디자인 프레임워크로 STDF 3을 적용하고 Tailwind CSS 4와 기본 테마 연결.
- VPS 실행을 위한 Node 어댑터 및 운영 서버 시작 명령 추가.
- 봇과 데이터베이스 연결은 미구현 상태로 유지하고 README에 현재 범위 기록.
- 후속 결정에 따라 `apps/bot`에 discord.js 기반 TypeScript 진입점과 토큰 환경 변수 예제 추가.
- 봇 개발·빌드·운영 실행 명령을 추가하고 루트 검사·빌드에 봇 포함.
- 루트 레이아웃에 공통 헤더·본문 컨테이너를 구성하고 첫 페이지의 콘텐츠 영역 분리.
- 인증·권한 검사를 연결할 서버 훅의 최소 틀 추가. 실제 인증과 접근 정책은 미구현.
- MSM1의 실사용 favicon·로고를 원본 그대로 가져와 공통 HTML·헤더에 연결.
- STDF 단일 테마 규약에 맞춰 전역 그레이·슬레이트 색상과 라이트·다크 모드 토큰 설정.
- MSM1과 동일한 Google Fonts Noto Sans KR 로딩 설정과 전역 폰트 적용.
- 내부 프로젝트명 `MonkeyScrimManager2`와 사용자 표시명 `Monkeybot`을 구분하는 규칙을 AGENTS·목적 문서·README에 명시.
- 웹 표시명을 `SERVICE_NAME`으로 통합하고 화면·브라우저 제목에서 프로젝트명 노출 수정.
- 웹 표시명 규칙 검사 `check:branding`을 루트 `pnpm check`에 연결해 잘못된 표기와 직접 작성 방지.
- `Monkeybot` 워드마크에 Geist Pixel Square를 적용하고 본문·UI의 Noto Sans KR과 구분하는 규칙 추가.
- STDF 사이트를 참고해 64px sticky 헤더·반응형 내비게이션·모드 전환과 본문 좌우 경계선 구성.
- 공통 경계선 토큰을 추가해 라이트·다크 모드의 레이아웃 구조선 통일.
- 공통 푸터를 추가하고 본문과 폭·경계선을 공유하도록 정리. 짧은 페이지에서도 화면 하단에 푸터 표시.
- `Monkeybot` 워드마크의 `font-brand`를 Geist Pixel에서 Jersey 10 regular 400으로 교체.
- MSM1을 참고해 푸터를 서비스 도메인·문서·이용약관·개인정보 처리방침과 운영 문의 안내로 구성하고 기존 서비스 주소에 연결.
- 한 페이지의 기능 조작 지점과 설명을 중복하지 않는 웹 UI 규칙 및 완료 전 화면 전체 검토 기준 추가.
- 푸터의 운영 문의 문구와 내부 구분선을 제거하고 여백을 줄여 간결하게 정리.
- 내 정보·길드·내전·매치·밴픽·전적·통계·관리의 빈 페이지 라우트 12개를 추가하고, 홈의 개발 확인용 UI 제거. 각 페이지는 공통 레이아웃과 제목만 표시.
- 문서·이용약관·개인정보 처리방침의 빈 페이지를 추가하고, 푸터 링크를 같은 탭에서 열리는 내부 경로로 변경.
- Riot 공식 ACCOUNT-V1 기반 계정·LoL 활성 지역 조회와 공통 서버 요청 처리를 추가하고, `apps/web/.env` 설정 예제 및 실행 방법 문서화.
- 참가자 프로필·개인 랭크 조회와 플랫폼 라우팅, 입력·응답 검증 추가.
- Data Dragon의 버전 목록·화면 표시용 정적 카탈로그·이미지 URL 생성 및 제한된 메모리 캐시 추가.
- Riot 연동을 계정·참가자 정보·정적 데이터의 7개 라우트로 축소하고, 사용처 미정인 조회·관련 모듈·테스트·환경 설정 제거.
- 외부 API는 현재 서비스 기능의 사용처를 확인한 뒤 추가하도록 프로젝트 규칙에 명시하고, 남은 경로의 목적·검증 방법을 `docs/riot-api.md`에 정리.
- ROFL2 헤더·종료 메타데이터 검증과 경기 시간·참가자·팀·승패·KDA·CS 추출 파서, 로컬 `rofl:inspect` 명령 추가. 원본 메타데이터 보존 및 공개 16.5·사용자 16.21 실제 파일 검증.
- 로컬 ROFL 원본과 분석 결과를 담는 루트 `samples/`를 Git 추적 대상에서 제외.
- ROFL2의 17·18바이트 청크 헤더를 실파일로 검증하고 Node 기본 Zstd로 자체 압축 해제 및 패킷 경계 파서 추가.
- `rofl:research` 명령으로 원본 사본·무변환 메타데이터·전체 해제 청크·압축 패킷 인덱스·실패 범위를 보존. 16.21 파일의 697개 청크·1,795,343개 패킷 구조를 추출하고, 미확인 패킷 의미와 검증 범위를 연구 문서로 구분.
- P0~P2 통계 33개와 최종 세팅을 선별하는 서비스용 파싱 모델 및 `rofl:project` 명령 추가. 누락·0·슬롯 순서·팀 결과 일관성을 검증하고 CC·사망 관련 원값의 미확정 단위 유지.
- 파일 지문·서비스 경기 문맥·팀/참가자 연결을 받는 적재 초안 모델 추가. 원본 식별자를 서비스 계정으로 추정하지 않으며 DB 연결·스키마·저장은 다음 단계로 유지.
- Drizzle ORM·`pg`·Drizzle Kit 의존성과 PostgreSQL 연결의 지연 초기화, 환경 변수, SQL 생성·적용 명령 추가. 스키마 진입점은 테이블 없이 준비하고 실제 DB 적용은 수행하지 않음.
- 기존 개발용 PostgreSQL Docker 인스턴스에 MSM2 전용 빈 DB·로그인 계정을 마련하고 로컬 환경 변수 연결. 실제 `getDb()` 경로의 읽기 쿼리로 접속·권한·테이블 0개 확인.
- 개발 PostgreSQL 컨테이너의 Compose 이름을 `msm2-dev`로 변경하고 기존 데이터 볼륨·이미지·포트로 재생성. MSM2 연결과 기존 데이터베이스 보존 확인.
