## 잘 작동하는 점

1. 역할과 읽기 순서: 운영자는 참가자 관리를, 참가자는 내 신청을 먼저 읽는다. 전적은 핵심 지표 뒤 MMR을 판단하고 개별 기록을 이어 읽는다. DOM과 시각 순서가 같다.
2. 작은 화면의 맥락: 기존 단일 선택 안내가 두 번째 팀까지 유지되고 실제 해제 버튼을 넓혔다. 이름·MMR·희망 외·전체7지표를 지우지 않고 줄바꿈·고정 열·스크롤로 보존했다.
3. 처음 시작과 해석: 실제 로그인/서버 상태의 다음 행동, 단일 역할별 목차, hover 없이 보이는 기존 그래프 값·방향이 불필요한 기억과 추측을 줄인다.
