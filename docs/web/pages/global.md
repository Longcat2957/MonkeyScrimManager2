# 전역 페이지

작성일: 2026-10-30. 모두 전역 범위 헤더를 쓴다([routing.md 3절](../routing.md#3-헤더)).

## `/` — 서비스 소개

**목적** 처음 온 사람이 Monkeybot이 무엇을 하는지 알고, 헤더에서 로그인·서버 선택으로 시작한다.

**권한** 누구나.

**화면**

```text
[h1] 디스코드 내전, 모집부터 전적까지          ← 문구는 확정 전 예시
[p]  한 문단 소개

[Steps] 모집 ─ 팀 편성 ─ 대진 ─ ROFL 기록      ← 데스크톱 가로, 모바일 세로(vertical)
        각 단계 desc 한 줄

(dev) ── 개발 바로가기 ───────────────────
[LinkCell 목록: 경로 이름 + 경로]
[LinkCell 목록: 컴포넌트 검증 · 오류 미리보기]
```

**구성**

| 영역 | 사용 | 메모 |
| --- | --- | --- |
| 소개 | `h1`, `p` | 워드마크를 본문에 다시 크게 쓰지 않는다(헤더에 있음) |
| 흐름 | `Steps` | `current`를 두지 않는다(진행 상태가 아닌 설명). 클릭 동작 없음 |
| 개발 바로가기 | `LinkCell` 목록 | `dev`에서만. 헤더 메뉴로 갈 수 있는 경로도 임시 ID가 필요하므로 유지 |

본문에 `시작하기`·`로그인`·`서버 선택` 버튼을 두지 않는다(헤더가 담당).

**미결정** 최종 소개 문구, 봇 초대·서버 등록 진입 제공 여부.

## `/me` — 내 정보

**목적** 내 Discord 계정 확인, 참가에 쓸 Riot 계정 연결, 전적 공개 범위 설정.

**권한** 로그인한 본인만. 비로그인 시 `load`에서 로그인으로 redirect.

**데이터**

```ts
{
  me: { userId, displayName, avatarUrl },
  riotAccounts: { id, gameName, tagLine, region, isPrimary }[],
  privacy: { profilePublic: boolean, showRiotId: boolean }  // 행이 없으면 둘 다 false
}
```

**화면** (한 열, `max-w-2xl`)

```text
[h1] 내 정보

[CellGroup]
  [img] 표시이름              Discord 계정        ← Cell (동작 없음 → 정적 행, 아래 메모)

[h2] Riot 계정                           [계정 추가]
[CellGroup]
  Hide on bush#KR1   대표   ›             ← Cell 클릭 → ActionPopover [대표로 설정 · 연결 해제]
  다른계정#KR2              ›
(없음) 연결한 Riot 계정이 없어요

[h2] 공개 범위
[CellGroup]
  프로필 공개        다른 서버 멤버가 내 전적을 볼 수 있어요     [Switch]
  Riot ID 표시       경기 기록에 Riot ID를 보여줘요            [Switch]
```

**구성**

| 영역 | 사용 | 동작 |
| --- | --- | --- |
| 본인 식별 | `<img>` + 텍스트를 `CellGroup` 모양의 `div`로 | 동작이 없으므로 `Cell`(버튼)을 쓰지 않는다 |
| 계정 추가 | `Button fill="lineLight"` → `Popup` | 폼: `Input title="Riot ID" placeholder="이름#태그"` → `조회` → 찾은 계정 표시 → `연결`. 조회 성공과 연결 완료를 다른 단계로 보여 준다 |
| 계정 행 | `Cell` (`title`=이름, `subTitle`=`#태그 · 지역`, 대표면 `Tag`) | 클릭 → `ActionMenu`: `대표로 설정`, `연결 해제`(→ `confirm`) |
| 공개 범위 | `Cell` + 오른쪽 `Switch`(`inside: 'state'`) + `subTitle`에 효과 설명 | 토글 즉시 저장. 실패 시 원복 + `toast.error`. 성공 알림 없음(스위치가 결과). 현재 값은 `detailChild`의 `sr-only` 텍스트로 보조기기에 알린다(보이는 문구는 모바일에서 줄바꿈돼 뺐다) |

화면 모드·로그아웃은 헤더가 담당하므로 여기에 두지 않는다.

**상태**

| 상황 | 처리 |
| --- | --- |
| Riot ID 형식 오류 | `Input state="error" tip="이름#태그 형식으로 입력해 주세요"` |
| 계정 없음 | `tip="계정을 찾을 수 없어요"` |
| Riot API 제한·실패 | `tip`에 "잠시 후 다시 시도해 주세요". 기존 연결 목록은 유지 |
| 이미 다른 사용자가 연결 | `tip="이미 다른 사용자에게 연결된 계정이에요"`. 상대 정보는 보여 주지 않는다 |
| 진행 중 내전에 쓰인 계정 해제 | 정책 결정 전에는 `연결 해제` 항목을 렌더링하지 않는다 |

**미결정** 소유권 확인 방법(조회만으로 연결할지), 해제 가능 조건, 공개 설정의 정확한 열람 대상, 선호 챔피언 제공 여부, 탈퇴·데이터 삭제 경로.

## `/docs` — 이용 문서

**목적** 모집 참여·팀 편성·대진 확인·ROFL 업로드 방법과 실패 시 할 일을 찾아 읽는다.

**권한** 누구나.

**화면** (`max-w-3xl`)

```text
[h1] 이용 안내
[nav 목차]  모집 참여 · 팀 편성 · 대진 · ROFL 업로드 · 자주 묻는 질문     ← 같은 문서 앵커 링크
[h2] 모집 참여 …
[h2] ROFL 업로드 …
[h2] 자주 묻는 질문
[Accordion] 질문 → 답
```

**구성** 본문은 네이티브 문서 요소, 목차는 `<nav><a href="#…">`, FAQ만 `Accordion`.
구현되지 않은 기능은 쓰지 않는다. 문의 수단이 정해지기 전 연락처를 넣지 않는다.

**미결정** 첫 공개 주제, 문의 경로.

## `/terms`, `/privacy` — 약관·개인정보 처리방침

**목적** 확정된 정책 본문 열람.

**권한** 누구나. 로그인·서버 오류와 무관하게 열려야 한다.

**화면** `h1` → `적용일 YYYY-MM-DD` → 조항 `h2`/`p`/`ol`. `max-w-3xl`. `/docs`와 세 페이지가 `layout.css`의 `.doc` 컴포넌트 클래스 하나로 제목·문단·목록 간격을 공유한다. 별도 래퍼 컴포넌트는 만들지 않는다.

본문이 확정되기 전에는 "준비 중이에요" 한 줄만 두고 적용일을 쓰지 않는다. 개인정보 처리방침 본문은 원본 ROFL 미보관 등 [데이터 보존 원칙](../../purpose.md#6-데이터-보존-원칙)과 일치해야 한다. 공개 설정 변경 링크를 본문에 두지 않는다(`/me`는 계정 메뉴에 있음).

**미결정** 본문·적용일·개정 이력, 개인정보 요청 경로.

## `/backoffice` — 서비스 운영

**목적** 서비스 운영자 업무. 업무 범위가 정해지기 전까지 제목만 둔다.

**권한** `users.isServiceAdmin`. 서버 관리자 권한으로 대체하지 않는다. `load`에서 검사하고 아니면 403.

업무가 정해지면 이 절에 화면을 추가한다. 그 전에는 통계·사용자 목록 같은 자리 채우기 UI를 만들지 않는다.

**미결정** 첫 운영 업무, 운영자 지정·회수 방법.

## `/dev/components` — 컴포넌트 검증

**목적** STDF와 서비스 공통 컴포넌트를 실제 페이지에 쓰기 전에 상태별로 확인한다.

**권한** `dev`에서만. 운영 404.

**화면** 컴포넌트별 `h2` 영역. 각 영역에 정상·로딩·빈·오류·비활성 변형을 나란히 렌더링하고, 오버레이는 여는 버튼을 둔다. 데이터는 `lib/mocks/component-demo/`.

우선 검증할 항목: `overlay` attachment(포커스·Escape·inert), `ActionPopover` inline/v 전환, `ImageList`의 `.rofl` 처리, `Popup` 위치 전환, `Button size="auto"` 높이, 다크 모드 토큰.

## `/dev/error`, `+error.svelte` — 오류 화면

구현됨. `큰 상태 코드` → `h1 제목` → `한 줄 설명` → (5xx만) `Button fill="lineLight"` `다시 시도`.

| 코드 | 제목 | 설명 |
| --- | --- | --- |
| 403 | 접근 권한이 없어요 | 운영자에게 이용 권한을 요청해 주세요. |
| 404 | 페이지를 찾을 수 없어요 | 주소가 올바른지 확인해 주세요. |
| 그 외 | 페이지를 불러오지 못했어요 | 잠시 후 다시 시도해 주세요. |
