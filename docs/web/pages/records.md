# 기록 페이지

활성 서버의 경기·전적·통계는 공개다. 프로필과 Riot ID는 [본인 공개 설정](global.md#me--내-정보)을 각각 따른다. 과거 기록은 당시 실출전자에게 귀속된다. 탈퇴하거나 연결 계정 소유자가 바뀌어도 기록을 다른 사람에게 옮기지 않는다.

## 표시 규칙

- 시리즈의 고정 A/B 팀과 세트별 블루/레드 진영은 다르다. 시리즈 점수에는 팀 이름을, 세트 결과에는 실제 진영을 쓴다.
- 확인할 수 없는 수치·시각·포지션을 0, 업로드 시각, 희망 포지션으로 보충하지 않는다. 합계·평균은 해당 지표의 유효 표본으로만 계산한다. 단위가 검증되지 않은 수치는 표시하지 않는다.
- 아이템·룬·주문은 구매 순서가 아니라 최종 세팅이다. Data Dragon에서 찾을 수 없는 ID는 임의의 이름이나 이미지로 바꾸지 않는다.
- 실제 서버는 합의되지 않은 업적·MVP·ACE·종합 평점을 표시하지 않는다. 개발 샘플 수치나 공식을 운영 평가 기준으로 사용하지 않는다.

## `/g/[guildId]/matches` — 경기 기록

기록 목록과 서버 홈의 최근 경기에는 정상 종료된 시리즈만 표시한다. ROFL로 기록한 유효 세트 점수가 해당 BO의 선승 조건과 확정 승자에 맞아야 한다. 대기·진행·중도 종료·취소 경기와 취소된 내전은 건수에도 포함하지 않는다. 진행 중 경기는 내전 대진에서 운영한다.

출전 선수의 공개 표시 이름과 실제 픽한 챔피언으로 검색한다. 둘 다 지정하면 같은 세트에서 그 선수가 해당 챔피언으로 플레이한 시리즈만 남는다. 모집 명단·벤치와 예정 라인업은 검색 대상이 아니다. 비공개·탈퇴 사용자의 이름으로 출전 여부를 알아낼 수 없다. 챔피언은 한국어 이름 또는 영문 ID를 입력한다.

상세 필터에는 내전명·시즌·경기 형식(BO1·3·5)·기간을 둔다. 내전명은 공백으로 나눈 단어를 모두 포함해야 한다. 자동 생성 팀명은 검색하지 않는다. 기본값은 전체 시즌·전체 기간이다. 날짜는 한국 시각 기준 양 끝을 포함한다. 실제 세트 시작 시각이 없으면 날짜를 추정하지 않고 기간 검색에서 제외한다. 잘못된 날짜는 입력 오류로 표시한다.

결과는 확인된 첫 세트 시작 시각, 없으면 내전 예정 시각의 최신순으로 20경기씩 표시한다. ROFL에는 절대 시각이 없으므로 예정 시각으로 순서와 날짜 묶음을 정하되 실제 경기 시각으로 표시하거나 기간 검색에 쓰지 않는다. 둘 다 없는 경기는 `일정 없음` 묶음으로 마지막에 둔다. 같은 날짜의 경기를 묶어 보여 주고, 각 행에서 내전·BO·시각·양 팀 최종 점수를 확인한다. 승리 팀은 이름·점수의 굵기와 `승` 표시로 구분한다. 선수나 챔피언으로 찾은 행을 열면 검색 조건이 일치한 첫 세트로 이동한다. 검색 조건과 페이지는 URL에 남는다.

## `/g/[guildId]/matches/[matchId]` — 경기 상세

시리즈 점수와 세트 선택 아래에서 양 팀의 선수 성적을 비교한다. 시리즈 점수판과 세트 비교표 모두 A팀을 왼쪽에 고정하고, 세트의 실제 블루·레드 진영은 진영 표시와 배경색으로 구분한다. 확정 라인업으로 확인된 포지션끼리 같은 행에 맞추고, 포지션을 모르면 각 팀의 기록 순서대로 짝짓는다. 좁은 화면에서는 포지션마다 두 팀 선수를 위아래로 쌓는다.

- 누구나 시리즈 점수·세트·진영별 선수 성적과 선수 상세를 조회한다. `game`을 생략하거나 없는 세트를 지정하면 기록된 마지막 세트를 보여 준다. 시리즈 승자 표시는 정상 종료에만 사용한다.
- 관리자는 양 팀의 5포지션 라인업을 경기 전체에 한 번 확정한다. 수동 편성의 확정 포지션을 재사용하고, 경매는 경기별로 배치·교환 후 확정한다. 선수를 같은 팀의 포지션 행 어디에나 끌어 놓거나, 선수를 선택한 뒤 자리 버튼을 누른다. 진출 팀의 직전 포지션은 다음 경기 초안에 반영한다. 결과 이력이 있으면 확정을 풀 수 없다.
- 진행 중에는 점수판 곁에 다음 세트의 예정 진영을 표시하고, 좁은 화면에서는 점수판 바로 아래에 둔다. 운영자가 `진영 설정`을 열 때만 입력과 저장 버튼을 보인다. 선택은 해당 경기·세트에만 적용하며 다음 세트에 자동으로 복사하거나 교대하지 않는다.
- 하드 피어리스에서는 양 팀이 이전 유효 세트에서 실제 사용한 챔피언을 안내한다. 취소 기록과 예정 로스터는 제외한다. 위반 자체가 ROFL 등록을 막지는 않는다.

### ROFL 업로드 팝업

1. 관리자 또는 확정 출전자가 진행 중 경기에서 다음 세트의 `.rofl` 파일 하나(최대 64MiB)를 선택한다. 예정 진영을 기본값으로 보여 주며, 정한 적이 없으면 어느 팀도 선택하지 않는다. 실제 블루 팀이 다르면 바꾸고 양 팀 진영을 직접 확인한다. 파일·진영 또는 대상이 바뀌면 확인도 다시 받는다.
2. `미리보기`는 파일을 서버에서 읽고 확정 라인업과 대조한다. 같은 창에서 세트·파일명, 블루·레드 팀과 승패, 출전자별 Riot ID·포지션·챔피언·킬/데스/어시스트를 확인한다. 새로 연결될 계정도 표시한다. 이때는 경기·계정 연결·MMR·Discord 게시를 기록하지 않는다. `수정`으로 돌아가면 파일을 다시 고를 필요가 없다.
3. `이대로 등록`은 같은 파일을 다시 전송한다. 서버는 권한·경기 revision·세트·라인업·중복과 미리보기의 귀속·결과가 여전히 일치하는지 확인하고 한 트랜잭션에서 반영한다. 다른 운영자가 상태를 바꾸면 이전 확인으로 저장하지 않는다. 별도 승인자나 원본 파일 보관은 없다.
4. 충돌이나 등록 응답 유실 시 파일을 자동 재전송하지 않고 최신 경기 상태를 확인한다. 개발 샘플만 여러 파일을 선택할 수 있으며, 다음 세트도 미리보기를 확인한 뒤 개별 등록한다.

**정정:** 관리자만 마지막 유효 세트를 취소할 수 있다. 이후 MMR 변경·후속 경기 작업이 역분개를 막으면 이유를 안내한다. 세트 순서를 잘못 입력했다면 취소한 뒤 올바른 순서로 등록한다. 취소한 파일은 같은 경기·확정 라인업·원래 블루 팀에서 다음 등록 세트에 사용할 수 있다. 상세 계약은 [ROFL 적재 모델](../../rofl-import.md)을 따른다.

## 개인 전적·서버 통계의 시즌 선택

서버 순위·개인 전적·통계는 활성 시즌이 기본이며, 종료 시즌을 선택하면 그 시즌만 읽는다. 전체 시즌을 합산하지 않는다. 활성 시즌이 없어도 과거 시즌을 선택할 수 있다. 개인 전적 링크는 선택 시즌을 유지한다. 취소 결과는 제외하고 중도 종료 전의 정상 세트는 보존한다.

게임과 경매는 별도 탭이며 시즌 선택을 공유한다. 호명 순위와 달리 전적 화면은 선택한 시즌에만 [경매 가격 집계 기준](scrims.md#경매-auction)을 적용한다. 취소된 내전과 무효화된 영입은 복기에서도 제외한다. 낙찰 기록으로 패찰 입찰가를 추정하지 않는다.

승률과 킬 관여율은 원래 비율로 정렬하고 표시할 때만 1% 단위로 반올림한다. 팀 총 킬이 0이면 킬 관여율을 계산하지 않는다. 개인 지표의 ‘상위 %’는 동점을 같은 순위로 보고 각 지표의 유효 인원으로 나눈 뒤 올림한다. 예를 들어 3위는 비교자가 10명이면 상위 30%, 17명이면 상위 18%다.

## `/g/[guildId]/players/[userId]` — 사용자 전적

시즌 전체 승패·MMR과 포지션 필터를 적용하는 분석 영역을 분리한다. 분석 영역에서는 지표와 백분위를 비교한 뒤 게임별 기록과 챔피언 성적을 확인한다.

- 선택 시즌의 승패·5포지션 MMR·듀오와 시즌 칭호 배지를 확인한다. 포지션과 게임 기록의 쪽 번호는 배지를 바꾸지 않는다. 시즌과 사용자가 확인됐지만 유효 MMR 반영이 없는 포지션은 1500이다. 원장 게임 수는 전적 게임 수와 다를 수 있다.
- 개인 경매 탭(`./[userId]/auction`)에서 선수로 낙찰된 내전과 영입 팀·팀장, 낙찰가와 시작 예산 대비 비율을 확인한다. 팀장은 별도로 경매별 영입 명단·지출·잔액과 반복 영입 선수를 확인한다. 게임 전적이 없는 선수도 조회할 수 있다.
- 포지션을 바꾸면 핵심·세부 지표, 비교 백분위, 챔피언별 성적과 게임 기록이 바뀐다. 시즌 전체 승패·MMR·듀오는 바뀌지 않는다. 같은 포지션 범위에 4게임 이상인 사용자만 백분위를 비교하며 지표가 없으면 레이더 축을 만들지 않는다. 경기일 미확인 기록이 섞이면 최근 10게임과 연속 승패는 추정하지 않는다.
- 챔피언 목록을 펼치거나 접고, 게임 기록은 10개씩 조회해 세트 상세로 이동한다. 듀오는 함께 3게임 이상 한 사람 중 승률 상·하위 각 최대 2명이며 한 사람을 양쪽에 반복하지 않는다.

## `/g/[guildId]/stats` — 서버 통계

시즌 요약 아래에 시즌 칭호를 전폭으로 배치하고, 그 아래에서 선수 리더보드와 챔피언 기록을 비교한다. 리더보드의 긴 사용자 이름은 줄바꿈해 전부 표시한다. 좁은 화면에서는 이름 열을 고정한 채 표 안에서 가로로 스크롤하고 링크로 챔피언 기록에 바로 이동한다.

- 핵심 지표는 선택 시즌의 완료 세트를 센다. 경기 시간·분당 킬 등은 필요한 값이 있는 세트만 계산한다. 포지션·최소 게임 필터는 시즌 전체 요약을 바꾸지 않는다.
- 경매 탭(`./stats/auction`)에서는 선수 이름을 찾아 최근 낙찰가·중앙값·범위·표본 수를 비교한다. 선수별 거래 내역에서 해당 경매 복기로 이동해 팀별 시작 예산과 영입 순서, 거래 직후 잔액, 최종 명단을 대조한다.
- 포지션과 최소 게임 수(기본 5, 범위 1~50)를 골라 리더보드를 비교한다. 이름 옆에는 선택 시즌의 해당 포지션 MMR을, `전체`에서는 유효하게 반영된 포지션 중 가장 높은 `최고 MMR`을 표시한다. 반올림 전 MMR 내림차순으로 전체를 정렬한 뒤 20명씩 본다. 동점은 고정된 공개 식별 키 순서이며 유효 반영이 없으면 순위와 점수는 `—`로 표시하고 마지막에 둔다.
- KDA·승률·게임·킬 관여·CS/분·피해/분·시야는 비교 지표로만 표시한다. 챔피언 표에는 포지션만 적용하며, 픽 수·승률 순으로 15개씩 보고 5픽 미만 승률은 표시하지 않는다.
- `새로고침`과 자동 갱신 중지는 별도 조작이다. 같은 조건은 30초 간격으로 갱신하고 쪽을 보존한다. 탭을 숨기거나 오프라인이면 진행 요청을 중단한다. 실패하면 마지막 결과를 유지하고 재시도 간격을 늘린다. 시즌에 기록이 없으면 0으로 채운 지표 대신 빈 안내와 시즌 선택을 제공한다.
- [시즌 칭호 15종](../../season-titles.md)은 서버 홈·통계·개인 배지에서 같은 선택 시즌의 순위를 사용한다. 칭호별 순위창은 공동 1위를 모두 표시하고 10위까지의 순위·값·유효 표본을 보여 준다. `가성비 킹`은 포지션별로 나눈다. 리더보드 필터나 기존 `recent=1` 주소는 칭호 순위를 바꾸지 않는다.
- 서버 홈과 통계의 캐러셀은 선택한 칭호 카드를 중앙에 두고 이웃 카드를 양옆에 겹쳐 표시한다. 아래 점으로 직접 고르거나 화살표·스와이프로 넘긴다. 공동 1위는 같은 기록을 한 번만 표시하고 선수별 표본을 구분한다. 배경 챔피언은 칭호를 위한 장식이며 선수의 사용 챔피언을 뜻하지 않는다. 배경 원본은 [Riot Data Dragon](https://ddragon.leagueoflegends.com/cdn/img/champion/splash/Azir_0.jpg)의 기본 스플래시다.
- 카드 안에서는 칭호명과 달성 조건을 먼저 읽고, 이어서 1위 기록과 보유자별 표본을 확인한다. 좁은 화면에서는 제목을 카드 본문 폭 전체에 표시하고 초상화는 기록 옆에 둔다.
