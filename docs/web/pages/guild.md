# 서버 페이지

## `/g/[guildId]` — 서버 홈

활성 서버는 누구나 열람한다. 다음 내전 일정 띠 바로 아래에 업적이 있을 때만 본문 전체 너비로 배치한다. 이어서 포지션별 서버 순위를 비교한다. 넓은 화면은 순위 오른쪽에 내전 현황을 두고, 좁은 화면은 순위 아래에 둔다. 포지션을 바꾸면 공통 선수가 새 순위로 이동하며, 모션 감소 설정에서는 즉시 표시한다. 시간 표시가 만료돼도 자동으로 시작하거나 모집을 마감하지 않는다.

- **다음 내전:** 본인이 선발·대기 중인 내전을 먼저 고른다. 없으면 빈자리가 있는 모집을 일정순으로 제시하고 일정 미정은 뒤에 둔다. 같은 내전은 현황 목록에 반복하지 않는다.
- **현황:** 모집부터 진행 중까지의 내전과 최근 종료 경기 최대 5개를 전환한다. 실제 경기 시각이 없으면 뒤로 보낸다. 한 영역의 조회 실패가 다른 영역을 막지 않는다.
- **순위:** 같은 서버의 시즌·포지션을 고른다. 현재 서버 멤버 중 선택 조건의 유효 MMR 반영이 한 게임 이상인 사람만 포함한다. 본인 순위가 아직 목록에 없다면 따로 표시한다. 다음 쪽과 선수 전적 링크는 선택 시즌을 유지한다. 추가 조회 실패 시 기존 명단에서 재시도한다.
- **시즌과 업적:** 시즌 변경은 순위에만 적용한다. 다음 내전·현황을 과거 상태로 돌리지 않는다. 실제 운영 업적은 기준 확정 전까지 게시하지 않는다.

## `/g/[guildId]/admin` — 서버 관리

Discord 소유자·실효 서버 관리 권한 또는 설정한 운영자 역할을 확인한다. 비로그인은 401, 소속이나 대상이 없으면 404, 권한이 부족하면 403이다. 모든 변경에서 현재 실행자와 대상의 소속·권한을 다시 검사한다. 서비스 운영자는 우회할 수 없다.

멤버·Discord 연동·변경 이력·시즌을 작업별로 나눈다. 넓은 화면에서는 작업 목록 옆에 선택한 내용을 표시하고, 좁은 화면에서는 목록을 위에 둔다.

| 탭 | 사용자 조작과 제약 |
| --- | --- |
| 멤버 | 서버 별명·사용자명으로 멤버를 검색하고 Riot 계정을 관리한다. 실제 평균 낙찰가와 집계 건수를 확인한 뒤 [호명 기준](scrims.md)에 쓸 보정가나 초기값을 설정한다. 둘 다 1~2,147,483,647P의 정수이며 개별적으로 비워 저장하면 해제한다. 실제 낙찰 기록은 수정하지 않는다. 관리자 표시는 읽기 전용이다. 서버 멤버 초대·추방·Discord 역할 부여는 Discord에서 한다. |
| Discord 연동 | 운영자 역할, 모집·엔트리·결과 채널을 고르거나 해제한다. 저장 후 본인의 관리 권한을 잃는 역할이나 봇이 게시할 수 없는 채널은 선택할 수 없다. 실제 역할·채널·게시 권한을 서버에서도 확인한다. 실패하면 기존 설정을 보존한다. |
| 변경 이력 | 계정 연결·해제·대표 지정, Discord 설정, 경매 초기값·보정가 변경의 대상·담당자를 최신순 20개씩 조회한다. 가격 자체는 이력에 복사하지 않는다. 권한 없는 사람에게 이력을 전달하지 않는다. 변경과 같은 트랜잭션에 남기고 세션·토큰·PUUID·요청 원문은 기록하지 않는다. |
| 시즌 | 현재 시즌과 종료 이력을 확인한다. 전환할 새 이름(앞뒤 공백 제외 1~100자)을 입력하고 현재·새 이름을 확인한다. 이름 재사용은 가능하다. 충돌하면 현재 시즌을 다시 읽고 동의를 새로 받는다. 최초 시즌이 없으면 조회로 만들지 않는다. |

**Riot 계정:** 조회는 소유권 인증이 아니다. 운영자가 조회 후 연결하며 첫 연결은 그 서버의 대표 계정이 된다. 같은 서버에서 다른 사용자와 계정을 공유할 수 없으며 다른 서버의 연결은 독립적이다. 같은 서버의 활성 신청에서 사용 중인 계정은 해제할 수 없다. 대표 해제 시 남은 연결 중 다음 대표를 정하며 과거 출전·MMR은 바뀌지 않는다. 조회·연결에는 실행자별 분당 10회 제한을 적용한다.

**시즌과 게시:** 시즌 전환은 봇 `/시즌`과 같은 서비스를 사용한다. 기존 내전·결과·MMR은 원래 시즌에 남고 새 모집부터 새 시즌을 쓰며 초기 MMR은 1500이다. 채널 미설정·Discord 게시 실패가 저장된 웹 변경을 취소하지 않는다. 봇 게시 복구는 [봇 운영 안내](../../bot.md)를 따른다.
