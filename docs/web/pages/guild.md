# 서버 홈·길드 관리 페이지 요구사항

작성일: 2026-10-29. 상태: 구현 전 요구사항 초안.

[공통 요구사항](../page-requirements.md)과 [라우트 설계](../routing.md)를 함께 따른다.
아래의 **기존 합의**는 기존 문서의 책임을 옮긴 것이며, **상호작용 초안**은 그 책임을 수행하기 위한 제안이다.
확인 필요 항목은 구현 전에 결정한다. DB 필드의 존재만으로 운영 기능이나 접근 정책이 확정되지는 않는다.

## `/g/[guildId]` — 서버 홈

### 역할

- **기존 합의:** 선택한 서버의 진행 중 내전과 최근 경기를 요약하고, 특정 내전·Match 상세로 진입하게 한다.
- 사용자는 이 서버에서 현재 참여하거나 확인할 내전이 있는지, 최근 어떤 결과가 등록되었는지 판단한다.
- 전체 목록 검색·모집 생성·통계 분석·설정 변경은 각 담당 페이지에서 수행한다.
- 서버 변경은 전역 서버 선택기, 내전·경기 기록·통계·관리는 길드 공통 메뉴가 담당한다.
  본문에 같은 목적지의 전체 보기 버튼이나 서버 선택기를 추가하지 않는다.

### 접근 대상

해당 서버 정보를 열람할 수 있는 사용자. 비로그인·서버 외부 사용자의 허용 범위는 접근 정책 확정이 필요하다.

### 필요한 정보

| 항목 | 요구사항 |
| --- | --- |
| 서버 식별 | 현재 선택한 서버의 이름·식별 정보. 길드 공통 영역에 표시하면 본문에서 반복하지 않음 |
| 진행 중 내전 | 내전 식별자·제목·운영 상태·참가 현황 중 진입 판단에 필요한 정보 |
| 최근 경기 | Match 식별자·팀·시리즈 점수·결과 상태·최근 결과를 구분할 시각 |
| 표시 범위 | 접근 권한과 공개 설정을 적용한 정보만 전달. 비공개 기록의 원문을 화면에서만 숨기지 않음 |

### 상호작용

다음은 상호작용 초안이다.

| 행동 | 입력·조건 | 결과 |
| --- | --- | --- |
| 진행 중 내전 선택 | 열람 가능한 특정 내전. 대상마다 이동 지점 하나 | `/g/[guildId]/scrims/[scrimId]`로 이동 |
| 최근 경기 선택 | 열람 가능한 특정 Match | `/g/[guildId]/matches/[matchId]`로 이동. 홈에서 업로드·결과 수정을 제공하지 않음 |
| 공통 서버 선택기로 다른 서버 선택 | 접근 가능한 다른 서버 | 선택한 서버의 홈 조회. 이전 서버 요약을 새 서버 정보처럼 표시하지 않음 |

진행 중 내전과 최근 경기의 대상이 동일한 Scrim에 속하더라도 각각 다른 상세 대상과 목적을 가진다.
하나의 Match가 여러 요약 영역에 반복되거나 같은 내전으로 이동하는 조작이 반복되지 않도록 선정한다.

### 상태별 처리

| 상태 | 필요한 반응 |
| --- | --- |
| 최초 로딩 | 데이터가 아직 없는 상태와 조회 중인 상태를 구별. 오래된 요약으로 운영 상태를 단정하지 않음 |
| 진행 중 내전 없음 | 해당 범위의 빈 상태만 표시. 모집 생성 조작은 내전 목록의 소유로 유지 |
| 최근 경기 없음 | 아직 표시할 경기 기록이 없음을 해당 위치에 표시. 가상의 점수나 통계로 채우지 않음 |
| 일부 조회 실패 | 정상 조회된 정보는 유지하고 실패한 정보만 구별. 부분 재조회 제공 여부는 공통 상태 규칙에 따름 |
| 서버 접근 불가·미존재 | 공통 접근 오류 처리. 비공개 데이터나 관리 메뉴를 빈 상태처럼 대신 노출하지 않음 |
| 상세 진입 사이 상태 변경 | 목적지에서 최신 상태·권한을 다시 확인. 홈의 과거 상태를 근거로 조작을 허용하지 않음 |

### 미결정 사항

- 진행 중 내전의 범위: 모집 중·편성 중을 포함할지, 어떤 순서와 개수로 보여줄지.
- 최근 경기의 범위: 완료된 시리즈만 포함할지, 결과가 일부 등록된 시리즈도 포함할지와 정렬 기준.
- 로그인·길드 소속·개인 공개 설정에 따른 열람 범위. 관리자라는 이유로 공개 설정을 우회한다고 가정하지 않는다.
- 최신 상태 반영 시점과 부분 조회 재시도 방식. 자동 갱신 주기나 실시간 전송 방식은 이 문서에서 정하지 않는다.

## `/g/[guildId]/admin` — 길드 관리

### 역할

- **기존 합의:** 해당 서버의 설정·멤버·길드별 관리자 권한을 관리한다.
- 길드 관리자는 서비스 운영자와 별도 권한이다. `/backoffice` 접근이나 서비스 운영자 지정은 이 페이지 책임이 아니다.
- 개별 내전의 참가자 선발·팀 편성·대진 조작과 ROFL 업로드를 이 페이지에 복제하지 않는다.
- 서버 이름·아이콘 등 Discord에서 온 정보를 표시하는 것과 Discord 서버 자체를 수정하는 기능을 구분한다.
  Discord 서버 관리 기능을 추가하는 것으로 해석하지 않는다.

### 접근 대상

해당 길드 관리자. 메뉴 노출과 별개로 서버에서 진입·변경 권한을 검사한다.
서비스 운영자 권한만으로 길드 관리 권한까지 갖는다고 가정하지 않는다.

### 필요한 정보

| 항목 | 요구사항 |
| --- | --- |
| 서버 범위 | 현재 작업 대상 서버. 다른 서버의 설정·멤버 ID로 요청해도 변경할 수 없어야 함 |
| 멤버 | 현재 서비스의 길드 연결과 길드 관리자 여부. Discord의 전체 서버 멤버 목록과 동일시하지 않음 |
| 설정 | 실제 운영 기능과 연결된 설정만 제공. 저장 항목이 있다는 이유만으로 빈 설정 메뉴를 만들지 않음 |
| Discord 게시 설정 후보 | 모집·결과 게시 채널. 스키마에 저장 기반이 있으나 봇 게시 기능의 범위·사용 시점은 확인 필요 |

스키마의 `guild_members.is_admin`은 Discord 자체 권한과 별도다.
Discord 서버 소유자·역할이 서비스 관리자 권한을 자동으로 갖는지, 최초 관리자가 어떻게 정해지는지는 미결정이다.

### 상호작용

다음은 상호작용 초안이며, 확인되지 않은 관리 정책을 확정하는 의미는 아니다.

| 행동 | 입력·조건 | 결과 |
| --- | --- | --- |
| 멤버 확인 | 현재 서비스에 연결된 길드 멤버 | 대상의 소속·길드 권한 확인. 목록 탐색 방식은 멤버 규모에 맞춰 결정 |
| 길드 관리자 권한 변경 | 대상과 변경값. 변경자 권한·대상 소속·보호 조건 검증 | 성공 시 확정된 권한 표시 |
| 합의된 서버 설정 편집·저장 | 현재 저장값과 구별한 편집값 | 성공 응답 후 저장 완료 표시. 실패 시 입력값 보존 |
| 편집 취소 | 저장되지 않은 변경이 있음 | 마지막 확인한 저장값으로 복귀 |
| Discord 게시 채널 설정 | 기능 제공 확정 시에만 제공. 해당 길드 채널·봇 게시 권한 검증 | 검증된 설정 저장. 미설정 허용 여부는 게시 정책에 따름 |

권한 부여·회수의 구체적인 보호 조건을 결정하기 전에는 자신이나 마지막 관리자의 권한 회수를 허용한다고 가정하지 않는다.
멤버 목록의 존재는 멤버 초대·추방·Discord 역할 변경·과거 기록 삭제 기능의 근거가 아니다.

### 상태별 처리

| 상태 | 필요한 반응 |
| --- | --- |
| 초기 로딩 | 권한·현재값 확인 전 변경을 허용하지 않음. 저장값을 임의의 기본값으로 대체하지 않음 |
| 설정 미등록 | 미설정 상태를 표시. 자동 게시 여부나 기본 채널을 추측하여 저장하지 않음 |
| 멤버 조회 결과 없음 | 실제 빈 결과와 조회 실패·접근 제한을 구별 |
| 저장 중 | 같은 변경의 중복 제출을 막고 완료 여부를 알림 |
| 검증 실패·외부 조회 실패 | 문제 대상과 수정·재시도에 필요한 이유를 제시. Discord 채널 확인 실패를 유효한 설정으로 취급하지 않음 |
| 다른 관리자와 저장 충돌 | 최신값과 충돌 사실을 확인하게 하고 자동 덮어쓰지 않음. 재적용 방식은 저장 정책에서 결정 |
| 작업 중 권한 회수 | 후속 변경을 거부하고 더 이상 조작 가능한 상태로 두지 않음. 이전 메뉴 노출을 권한 근거로 사용하지 않음 |
| 직접 접근 권한 없음 | 공통 접근 오류 처리. 설정·멤버 자료를 먼저 전달한 뒤 화면만 가리지 않음 |

### 미결정 사항

- 최초 길드 관리자 부여 방식, 권한 위임·회수 가능 주체, 자신·마지막 관리자의 권한 변경 규칙.
- 현재 서비스 멤버 연결의 생성·해제와 Discord 소속 동기화 기준. 서비스 내 멤버 제거 기능의 필요 여부.
- Discord 게시 설정의 제공 시점, 채널 미설정·삭제·봇 권한 상실 시 게시 동작.
- 이 페이지에서 실제로 편집할 서버 설정 목록. MMR 시즌 운영·점수 조정 등은 저장 구조만으로 추가하지 않는다.
- 설정 변경의 적용 시점과 동시 수정 검증 방식. 이미 모집 중인 내전이나 게시된 메시지에 미치는 영향.
- 길드 공개 정책을 별도 설정으로 제공할지와 개인 공개 설정과의 관계. 현재 라우트 책임만으로 우선순위를 확정하지 않는다.
