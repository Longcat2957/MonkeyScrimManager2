# 내전 모집·편성·대진 페이지

작성일: 2026-10-29. 상태: 구현 전 요구사항 초안.

[공통 요구사항과 전체 색인](../page-requirements.md) · [라우트 설계](../routing.md)

## 문서의 기준

- **기존 합의:** [프로젝트 목적](../../purpose.md)과 라우트 설계가 정한 책임·경로·업무 범위다.
- **데이터 계약:** [DB ERD](../../database-erd.md)와 [스키마](../../../apps/web/src/lib/server/db/schema.ts)의 모집·편성·대진 제약을 설명한다. 저장할 수 있다는 사실만으로 화면 기능을 확정하지 않는다.
- **상호작용 초안:** 각 페이지의 정보와 상호작용을 구체화한 제안이다. 권한·상태 전환 등 미결정 사항은 구현 전에 확정한다.
- 아래의 **내전 운영 권한 보유자**는 해당 내전에 대한 작업 권한을 서버에서 확인받은 사용자를 뜻한다. 생성자·길드 관리자·팀장에게 어떤 권한을 줄지는 아직 정하지 않았다.

## 작업의 소유 위치

| 작업 | 담당 페이지 | 다른 페이지에서의 처리 |
| --- | --- | --- |
| 모집 생성 | `/g/[guildId]/scrims` | 생성 버튼을 반복하지 않음 |
| 참가 신청·철회, 참가자 선발, 내전 운영 상태 | `/g/[guildId]/scrims/[scrimId]` | 현재 상태만 조회 |
| 팀·포지션 배정, 경매 운영과 구매 이력 | `…/[scrimId]/teams` | 최종 편성 결과만 필요한 범위에서 조회 |
| 라운드·대진 구성과 진행 결과 | `…/[scrimId]/bracket` | 개별 Match는 경기 상세에서 조회 |
| ROFL 업로드·Game 결과와 통계 | `/g/[guildId]/matches/[matchId]` | 대진에서 해당 Match로 이동 |

개별 내전의 요약·팀 편성·대진 이동은 내전 공통 메뉴가 담당한다.
페이지 본문에 같은 목적지 버튼이나 단계별 이동 카드를 다시 만들지 않는다.

## `/g/[guildId]/scrims` — 내전 목록

### 역할

**기존 합의:** 선택한 서버의 내전을 찾고 모집 생성 모달을 여는 페이지다.
웹과 Discord 봇에서 생성한 내전을 같은 목록과 상세 경로에서 다룬다.

### 접근 대상

열람자는 공개·접근 정책이 허용하는 내전을 보며, 생성은 별도의 작업 권한이 필요하다.

### 필요한 정보

- 내전 ID·제목·운영 상태·예정 시각·편성 방식. 예정 시각이나 방식이 미정이면 그대로 구분한다.
- 실출전 정원, 활성 신청 수와 전체 신청 정원. 신청 인원을 확정 참가 인원처럼 표시하지 않는다.
- 목록의 조회 범위, 다음 결과의 존재 여부, 현재 사용자의 생성 가능 여부.

### 상호작용

| 사용자 행동 | 입력·조건 | 성공 후 결과 |
| --- | --- | --- |
| 내전 찾기 | 운영 상태를 기준으로 범위를 선택. 검색·기간 조건은 실제 탐색 필요에 따라 확정 | 조건에 맞는 목록을 표시하고 상세에서 돌아왔을 때 탐색 맥락을 유지 |
| 내전 열기 | 목록에서 특정 내전 하나 선택 | 같은 서버의 내전 상세로 이동 |
| 모집 생성 시작 | 생성 권한 확인 후 모달 열기 | 해당 서버가 고정된 생성 입력 표시 |
| 모집 생성 제출 | 아래 생성 정보와 유효성 검사 | 생성된 내전 상세로 이동. 중복 제출은 새 내전을 중복 생성하지 않음 |
| 생성 취소 | 제출 전 모달 닫기 | 목록과 조회 조건 유지. 변경 내용을 버리는 기준은 공통 폼 규칙 적용 |

생성 입력 후보는 제목, 예정 시각, 팀 수, 추가 신청 정원, 편성 방식, 하드 피어리스 기본값이다.
이는 현재 데이터 모델에 대응하는 **초안**이며 필수 여부·기본값·허용 팀 수를 그대로 확정하지 않는다.
편성 방식은 모집 중 미정일 수 있으나 팀 편성에 들어가기 전에는 결정되어야 한다.
MMR 시즌의 지정 주체·시점은 별도 결정하며, 사용자가 이해할 근거 없이 생성 폼에 추가하지 않는다.

### 상태별 처리

- **조회 중:** 목록 조회와 생성 제출의 대기를 구분한다. 조회 중 임시 빈 목록을 내전 없음으로 설명하지 않는다.
- **내전 없음 / 조건 일치 없음:** 서버에 내전이 없는 경우와 검색 결과가 없는 경우를 구분한다. 빈 상태에 두 번째 생성 버튼을 만들지 않는다.
- **입력 오류:** 문제가 있는 입력과 수정 방법을 해당 입력에서 알린다. 제목·예정 시각 등 다른 입력은 보존한다.
- **생성 실패·권한 변경:** 성공 전에는 생성 완료로 표시하지 않는다. 결과가 불확실하면 재전송 전에 생성 여부를 확인할 수 있어야 한다.
- **데이터 계약:** 실출전 정원은 팀 수 × 5명이고 전체 신청 정원은 실출전 정원 + 추가 신청 정원이다. 추가 신청은 팀 수를 늘리지 않는다.

### 미결정 사항

생성 권한, 지원 팀 수, 생성 입력의 필수값·기본값, 목록 기본 정렬·검색 범위·페이지 처리,
예정 시각의 표시 시간대와 지난 시각 허용 여부를 확정한다.

## `/g/[guildId]/scrims/[scrimId]` — 모집·참가·운영 요약

### 역할

**기존 합의:** 해당 내전의 모집·참가 현황과 운영 상태를 확인하는 페이지다.

### 접근 대상

참가 희망자와 참가자는 자신의 신청을 관리하고, 내전 운영 권한 보유자는 참가자를 관리한다.
보기 권한과 참가·운영 권한은 구분하며, URL을 직접 열어도 같은 조건을 검사한다.

### 필요한 정보

- 내전 제목·예정 시각·운영 상태·편성 방식·정원과 모집 현황. 공통 내전 영역에서 이미 표시한 정보는 본문에 반복하지 않는다.
- 참가자의 당시 표시 이름, 선택한 Riot 계정, 희망 포지션, 현재 신청 상태. 공개 범위가 허용하는 정보만 제공한다.
- 자신의 신청 상태와 신청·변경·철회 가능 여부, 불가능한 경우 그 이유.
- 내전 운영 권한 보유자에게 필요한 선발·대기·철회·제외 이력과 다음 운영 작업을 막는 조건.

### 상호작용

| 사용자 행동 | 입력·조건 | 성공 후 결과 |
| --- | --- | --- |
| 참가 신청 | 본인 계정과 희망 포지션 선택. 계정 연결 조건은 확정된 정책 적용 | 서버가 수락한 현재 신청 상태와 신청 인원 반영 |
| 신청 정보 변경 | 변경 가능한 모집 단계에서 계정·희망 포지션 수정 | 같은 참가자의 현재 신청 정보 갱신 |
| 신청 철회 | 현재 활성 신청이 있고 철회 가능한 단계 | 철회 상태와 정원을 갱신하고 이전 신청 이력 보존 |
| 재신청 | 철회·제외 후 정책이 허용하는 경우 | 같은 참가자에 새 신청 이력 생성 |
| 참가자 선발·대기 지정 | 내전 운영 권한 보유자가 참가 대상과 상태 선택 | 선발·대기 수와 해당 참가자의 상태 갱신 |
| 참가자 제외 | 내전 운영 권한 보유자가 대상과 사유 확인 | 제외 이력을 남기고 미확정 편성에 미치는 영향 반영 |
| 모집 정보·편성 방식 결정 | 내전 운영 권한 보유자가 현재 단계에서 허용된 항목 수정 | 같은 내전의 정보 갱신. URL 변경으로 편성 방식을 바꾸지 않음 |
| 운영 단계 변경 | 현재 상태에서 허용된 작업만 실행 | 검증된 새 상태와 다음 작업의 가능 여부 반영 |
| 참가자 전적 보기 | 사용자 연결과 열람 권한이 있는 참가자 선택 | 해당 서버의 `/players/[userId]`로 이동 |

**데이터 계약:** 신청은 선발 전·선발·대기·자진 철회·운영 제외로 구분한다.
신청 순서로 자동 선발하거나 철회 시 대기자를 자동 승급한다고 가정하지 않는다.
활성 신청은 참가자당 하나이며 같은 내전의 사용자·Riot 계정 중복 참가를 허용하지 않는다.
팀 편성을 시작하려면 선발 수가 실출전 정원과 일치해야 한다.

### 상태별 처리

- **모집 중:** 미신청·신청 완료·대기·선발·철회·제외를 구분한다. 정원 마감과 본인의 신청 제한도 구별한다.
- **계정 준비 미완료:** 신청을 막는 실제 조건을 한 번 안내한다. 계정 연결은 `/me`의 책임이며 여기서 중복 구현하지 않는다.
- **편성·대진 진행 단계:** 모집 입력의 수정 가능 범위를 서버 정책에 맞춰 제한한다. `status` 열의 값을 그대로 전환 버튼 목록으로 만들지 않는다.
- **종료·중도 종료·취소:** 상태와 남아 있는 참가 기록을 조회한다. 취소와 중도 종료를 같은 의미로 표시하지 않는다.
- **경합:** 웹·봇의 동시 신청, 정원 마감, 타 내전 운영 권한 보유자의 선발 변경 시 최신 상태를 보여 주고 처리되지 않은 변경을 설명한다.
- **누락 정보:** 사용자 연결이 사라진 참가 기록은 이름과 이력을 보존하되 잘못된 프로필 링크를 만들지 않는다.
- **작업 실패:** 입력은 가능한 한 유지하고 상태 변경을 성공한 것처럼 표시하지 않는다. 페이지 자체를 볼 수 없는 오류는 공통 오류 계약을 따른다.

### 미결정 사항

운영 권한과 위임 범위, 계정 미연결 참가 허용 여부, 희망 포지션 개수·순위 규칙,
신청 수정·철회·재신청의 마감 시점, 제외 사유의 공개 범위, 선발 방식·확정 작업을 정한다.
내전 시작·완료·취소·중도 종료의 조건과 영향, 모집 단계로 복귀 가능한 범위도 필요하다.
이 문서는 단계별 버튼이나 모든 상태 사이의 전환을 확정하지 않는다.

## `/g/[guildId]/scrims/[scrimId]/teams` — 팀 편성과 경매

### 역할

**기존 합의:** `formationMethod`에 따라 수동 편성 또는 경매를 수행하고, 완료 후 최종 팀과 구매 이력을 조회한다.
두 방식과 10인·20인 내전은 같은 경로를 사용한다.

### 접근 대상

열람자는 편성 결과를 확인하고 내전 운영 권한 보유자는 허용된 편성 작업을 수행한다.
경매 팀장이라는 사실만으로 웹 입찰·편집 권한을 부여하지 않는다.

### 필요한 정보

- 선발 참가자와 희망 포지션, 팀별 배정 인원·포지션, 미배정 인원, 편성 완료 조건.
- 경매 방식에서는 팀장·시작 포인트·잔여 포인트, 현재 후보와 진행 상태, 후보 등장 이력, 유효 구매와 정정 이력.
- 참가 판단에 필요한 전적·MMR을 제공한다면 공개 범위와 기준 시즌·표본을 함께 전달한다. 제공할 지표는 별도 확정한다.

### 상호작용

| 작업 방식 | 사용자 행동과 입력 | 성공 후 결과·조건 |
| --- | --- | --- |
| 공통 | 팀 이름 설정, 편성 가능 대상 확인 | 해당 내전의 팀과 선발 참가자만 다룸 |
| 수동 | 참가자별 팀·포지션 지정 또는 미확정 배정 해제 | 미배정 수·팀 정원·포지션 충돌을 갱신. 드래그만으로 조작하게 만들지 않음 |
| 수동 | 편성 확정 | 정원·중복·포지션·선발 상태를 서버가 검증한 뒤 최종 팀으로 표시 |
| 경매 준비 | 팀장과 팀별 시작 포인트 설정 | 시작 가능 조건과 부족한 설정 표시 |
| 경매 운영 | 후보 선택·등장, 낙찰 팀과 가격 기록, 유찰 처리 | 후보 상태·영입·잔여 포인트·팀 배정을 일관되게 갱신 |
| 경매 예외 | 허용된 유찰자 재등장·수동 배정·구매 정정 | 이전 시도·거래를 보존하며 현재 유효 결과와 구분 |
| 경매 마무리 | 최종 편성 검증 후 완료 | 확정된 팀과 구매 이력을 조회하는 상태로 전환 |

경매 운영의 입력 주체·채널은 **미결정**이다. 위 표는 기록해야 할 상호작용을 정리하며,
팀장의 온라인 입찰, 자동 타이머, 자동 추첨·낙찰, 실시간 전송 방식을 요구하지 않는다.
설계 확정 시 웹에서 제공하는 행동만 남기고 봇·외부 진행과의 역할을 구분한다.

### 상태별 처리

- **방식 미정 / 선발 미완료:** 편성 불가 조건을 표시한다. 모집·선발을 이 페이지에서 다시 구현하지 않는다.
- **수동 편성 중:** 저장 대기와 반영 완료를 구분한다. 다른 내전 운영 권한 보유자의 변경을 덮어쓰기 전에 충돌을 드러낸다.
- **경매 준비 / 진행 / 완료 / 취소:** 현재 후보 없음과 후보 목록 로딩 실패를 구분한다. 경매 취소를 내전 취소로 간주하지 않는다. 시작 후 팀·팀장·시작 포인트 변경은 허용하지 않는 데이터 계약을 따른다.
- **구매 검증 실패:** 예산 부족·이미 영입된 대상·현재 후보 변경 등 실패한 조건을 해당 작업에 표시하고 기존 포인트를 유지한다.
- **데이터 계약:** 열린 후보는 경매당 하나이며 유효 영입은 참가자당 하나다. 0점 낙찰과 가격 없는 수동 배정을 구분한다. 구매 정정은 원래 값을 덮어쓰지 않는다.
- **경기 시작 이후:** 기존 팀을 재편성하지 않는다. 재편성이 필요하면 새 내전을 모집하는 계약을 따른다.
- **완료·중도 종료:** 최종 편성과 남아 있는 이력을 조회한다. 조회 화면에 실행할 수 없는 편성 컨트롤을 계속 노출하지 않는다.

### 미결정 사항

수동 편성의 저장 단위·확정 해제 범위, 포지션 미지정 허용 여부, 팀 이름의 입력 규칙,
경매 시작 포인트·가격 단위·낙찰 확정 주체·후보 선정·유찰 처리·취소 후 처리 규칙을 정한다.
구매 정정 권한과 허용 시점, 시작 전 팀장 교체·경매 재개 범위, 구매 이력 공개 범위도 필요하다.

## `/g/[guildId]/scrims/[scrimId]/bracket` — 라운드·대진 운영

### 역할

**기존 합의:** 라운드와 대진을 구성하고 시리즈 진행 결과를 확인하는 페이지다.
Game 결과의 등록과 상세 통계는 Match 상세의 책임이다.

### 접근 대상

내전 운영 권한 보유자는 대진 구성을 관리하고 열람자는 참가 팀·연결 관계·집계 결과를 확인한다.

### 필요한 정보

- 라운드 순서와 BO 형식, 각 대진의 두 자리, 직접 지정 팀 또는 앞선 대진 승자 연결.
- 아직 결정되지 않은 자리, 연결된 Match, 실제 시리즈에 적용된 BO·하드 피어리스 설정.
- 완료 Game에서 집계한 시리즈 점수와 Match 상태, 확정된 경우의 승자.
- 현재 변경 가능한 대진과 변경을 막는 조건. 아직 없는 결과를 패배·탈락으로 계산하지 않는다.

### 상호작용

| 사용자 행동 | 입력·조건 | 성공 후 결과 |
| --- | --- | --- |
| 라운드·대진 구성 | 내전 운영 권한 보유자가 순서·BO와 대진 자리를 지정 | 같은 내전의 팀과 이전 대진 연결을 검증한 구성 표시 |
| 대진 자리 변경 | 팀 직접 지정 또는 이전 대진 승자 선택 | 중복·순환·미정 상대 등 검증 결과와 변경된 연결 표시 |
| 시리즈 연결·생성 | 두 팀과 적용 규칙을 확정할 수 있는 상태 | 해당 대진에서 유일한 Match 상세 진입 제공 |
| 경기 상세 열기 | 연결된 특정 Match 선택 | `/g/[guildId]/matches/[matchId]`로 이동 |
| 결과 변화 확인 | ROFL 결과 등록에 따른 최신 집계 조회 | 시리즈 점수·확정 승자·후속 대진의 결정 여부 반영 |

라운드·대진 자동 생성, 승자의 다음 자리 자동 반영 시점, Match 생성 시점은 **미결정**이다.
표의 작업을 모두 별도 버튼으로 만들라는 의미가 아니며, 확정된 운영 흐름에서 필요한 조작만 제공한다.

### 상태별 처리

- **팀 미확정 / 대진 미구성:** 준비가 필요한 조건을 표시하고, 아직 없는 대진을 가짜 경기로 채우지 않는다.
- **상대 미정:** 이전 경기 결과 대기와 직접 팀 지정 대기를 구분한다. 한 팀만 정해진 상태를 자동 승리로 간주하지 않는다.
- **진행 중 / 결과 대기:** 서비스에 등록된 시리즈 상태만 보여 준다. 밴픽·픽 순서·실시간 경기 진행을 입력받지 않는다.
- **완료 / 중도 종료 / 취소:** 실제 결과와 상태를 보존한다. 미완료 시리즈에 승자를 임의로 부여하지 않는다.
- **변경 제한:** Game 생성 후 시리즈 A/B 팀 변경, 경기 시작 후 BO·피어리스 변경은 허용하지 않는 데이터 계약을 따른다.
- **조회 실패·동시 수정:** 마지막으로 확인한 구성과 최신 변경 필요 여부를 구분하고, 저장 실패를 새 대진 반영으로 표시하지 않는다.
- **좁은 화면:** 라운드와 두 팀의 연결을 읽을 수 있어야 하며, 가로 드래그가 유일한 탐색·편집 수단이 되어서는 안 된다.

### 미결정 사항

지원 대진 형식, 기본 구성과 수정 가능 시점, 부전승·순위 결정전 필요 여부, Match 생성·승자 반영 시점,
부분 완료 상태에서의 대진 수정 정책을 정한다.
Match 단위 취소·중도 종료의 조작 위치와 권한은 경기 상세 요구사항과 함께 결정한다.
하드 피어리스의 실제 사용 챔피언 안내는 Match 상세가 담당하며, 이 페이지에 같은 안내를 복제하지 않는다.
