# 라우트·레이아웃·내비게이션

## 경로와 접근 조건

모든 서버 화면의 접두사는 `/g/[guildId]`다. 일반 조회는 로그인이나 서버 소속을 요구하지 않는다. 비활성 서버와 해당 서버에 없는 대상은 404다. 서버·내전·경기 ID를 섞어 다른 서버의 데이터를 조회할 수 없다.

| 경로 | 용도 |
| --- | --- |
| `/` | 서버 선택. 실제 로그인 세션에 소속 활성 서버가 있으면 첫 서버 홈으로 303 이동 |
| `/auth/discord`, `/auth/discord/callback`, `/auth/logout` | OAuth + PKCE 로그인·복귀, POST 로그아웃 |
| `/me`, `/backoffice` | 본인 정보, 서비스 운영자 전용 백오피스 |
| `/docs`, `/terms`, `/privacy` | 공개 이용 안내·약관·개인정보 처리방침 |
| `/dev/components`, `/dev/error` | 개발 전용 컴포넌트·오류 예시. 운영에서는 404 |
| `/g/[guildId]` | 서버 홈 |
| `…/scrims`, `…/scrims/[scrimId]` | 내전 목록·모집 생성, 내전 요약·참가자 |
| `…/scrims/[scrimId]/manual`, `…/scrims/[scrimId]/auction` | 수동 편성·경매. 저장된 방식이 다르면 해당 방식으로, 미정이면 요약으로 307 이동 |
| `…/scrims/[scrimId]/bracket`, `…/scrims/[scrimId]/result` | 대진·결과. 종료·중도 종료는 결과로, 미종료는 대진으로 이동. 정상 종료한 단일 경기 결과는 경기 상세로 이동 |
| `…/matches`, `…/matches/[matchId]` | 경기 기록, 시리즈·세트·ROFL 등록 |
| `…/players/[userId]`, `…/stats` | 사용자 전적·서버 통계. 사용자 링크는 공개 설정에 맞는 식별자를 사용 |
| `…/players/[userId]/auction`, `…/stats/auction` | 개인 경매 이력·서버 거래 장부. 게임 기록과 같은 공개 정책과 시즌 적용 |
| `…/admin` | 현재 서버 관리자만 이용하는 관리 화면 |

서버 목록은 로그인한 사용자의 소속 서버만 담는다. OAuth가 명시한 복귀 경로를 존중하며, `/`의 기본 서버 이동은 실제 세션에만 적용한다. `mock=1` 개발 미리보기는 운영 인증이 아니다.

## URL 상태

| 화면 | 쿼리 | 기본값과 적용 범위 |
| --- | --- | --- |
| 서버 홈 순위 | `season` | 활성 시즌. 다음 내전·최근 경기는 바뀌지 않음 |
| 내전 목록 | `status=all\|recruit\|active\|done`, `includeCancelled=1`, `page` | 전체, 취소 제외, 1쪽. 20개씩 |
| 경기 기록 | `player`, `champion`, `q`, `bo`, `from`, `to`, `season`, `page` | 정상 종료한 시리즈만 표시. 출전 선수·챔피언 픽과 내전명(`q`)·형식·시즌·기간을 함께 검색 |
| 경기 상세 | `game` | 유효한 ID가 없으면 기록된 마지막 세트 |
| 사용자 전적 | `season`, `position`, `page` | 활성 시즌, 전체 포지션, 1쪽 |
| 서버 통계 | `season`, `position`, `min`, `recent=1` | 활성 시즌, 전체 포지션, 최소 5게임(1~50). 최근 필터는 개발용 업적 전용 |
| 경매 기록 | `season`; 서버 장부의 `q`, `player`, `page`, `archive`, `auction` | 선수 이름 검색과 펼친 선수, 선수·완료 경매 쪽을 보존한다. `auction`은 같은 시즌의 내전 ID, `#signing-…`은 복기에서 강조할 영입이다 |
| 서버 관리 | `tab=members\|discord\|audit\|seasons`, `q`, `page` | 멤버, 빈 검색어, 1쪽. 탭을 바꾸면 검색·쪽 초기화 |
| 백오피스 | `page` | 서비스 운영자 변경 이력의 쪽 번호 |

선택 시즌은 같은 서버의 UUID만 허용한다. 명시한 UUID가 잘못되거나 비었으면 400, 없거나 다른 서버의 시즌이면 404다. 순위·개인 전적·통계의 시즌 변경은 쪽·offset을 초기화하고 다른 조건은 유지한다. 경기 검색·기간·시즌은 조회 시 함께 적용한다.

팝업·참가자 선택·편성 자리·서버 홈 현황 탭·통계표 정렬과 내부 쪽 번호는 URL에 저장하지 않는다. 서버 아래 `ranking`은 선택한 시즌·포지션의 추가 순위, `stats/live`와 `scrims/[scrimId]/auction/live`는 현재 화면과 같은 권한의 읽기 응답이다. 독립 화면이나 입찰 API가 아니다.

## 레이아웃과 메뉴

- [루트 레이아웃](../../apps/web/src/routes/+layout.svelte)이 본문 건너뛰기, `AppHeader`, `main`, 푸터, 확인창과 토스트를 한 번씩 둔다. 1024px 이상에서는 왼쪽 레일, 그 미만에서는 상단 바와 오른쪽 메뉴 시트를 쓴다.
- 데스크톱에서는 계정 영역 위의 버튼으로 레일을 접어 본문을 넓힌다. 접힌 레일의 버튼과 링크는 44×44px이며 아이콘을 정중앙에 둔다. 메뉴 순서와 현재 메뉴 강조, 서버·계정 메뉴는 그대로 유지한다. 접기 상태는 브라우저에 저장하며 모바일 메뉴에는 적용하지 않는다. 모션 감소 설정에서는 너비를 즉시 전환한다.
- 서버 메뉴는 서버 홈·내전·경기 기록·통계와 관리자 전용 관리다. 로그인 사용자는 `/` 이외의 화면에서 서버를 전환한다. 계정 메뉴에는 내 정보, 권한이 있는 경우 백오피스, 로그아웃과 테마 전환이 있다. 비로그인 사용자도 테마를 전환할 수 있다. `/`의 로그인은 본문이 담당한다.
- 서버 화면의 `미니게임`은 레일 또는 모바일 메뉴에서 연다. 코인토스·사다리·룰렛은 브라우저 안에서만 실행하며 현재 내전·대진·경매 데이터를 읽거나 바꾸지 않는다.
- 사다리타기는 처음부터 2~6인 사다리판을 보여 준다. 위쪽 출발점에는 이름을, 아래쪽 도착점에는 결과를 입력한다. 줄바꿈·탭으로 구분한 목록도 붙여넣을 수 있다. 판 중앙에서 시작한 뒤 출발점을 누르면 같은 판에서 해당 경로를 따라간다. 전체 결과 보기와 입력을 보존하는 다시 편집을 제공한다.
- 내전 하위 레이아웃은 자식 화면을 렌더링한다. 각 작업판과 경기 상세가 `ScrimSummary`에 자신의 문맥을 전달해 제목과 `모집·참가자`, `팀 편성`, `대진·경기`, `결과`를 한 번만 표시한다. 방식 미정인 편성과 미종료 결과는 비활성이다. 종료 후에는 대진 대신 결과로 이동한다.
- 푸터에는 문서·이용약관·개인정보 처리방침과 이메일 문의가 있다. 별도 문의 접수 화면은 없다.

경로 구현과 서버 핸들러는 [routes](../../apps/web/src/routes/), 메뉴의 경로·현재 상태 판정은 [navigation.ts](../../apps/web/src/lib/components/layout/navigation.ts)를 참조한다.
