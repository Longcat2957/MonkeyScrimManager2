2026-11-14. 검토자 `/root/formation_records`. 루트 작업자가 촬영한 before/after `ui.json`의 **24장씩48장을 모두 실제 `view_image`로 열어 읽었다**. 단계 crop40장과 통계 viewport8장이다. 검토자는 UI 소스·ignore를 바꾸거나 새 스크린샷/검사 매트릭스를 추가하지 않았다. 경로·뷰포트·최종 SHA-256·읽기 여부와 계산값은 [ui-proof.json](ui-proof.json)을 따른다.

## 대표 표본의 계산 대비

독립 신규 Playwright MCP 탭에서 `/g/devGuild001/scrims/devScrim007/manual`,390×844를 primary/dark로 확인했다. `document.fonts.ready` 뒤 화면이 정착된 상태에서 예정 제목3개와 번호3개씩 **총12표본**을 측정했다. 새 촬영이나 목 데이터 쓰기는 없다.

CSS computed color를 1×1 Canvas2D sRGB에서 RGBA로 읽고, HTML부터 해당 요소까지 `background-color`를 alpha 합성했다. 전경 alpha까지 합성한 뒤 sRGB 선형화·상대휘도 비율을 계산했다. Canvas의 실제 colorSpace도 `srgb`였다.

| 테마 | 글자/번호 sRGB | 합성 바탕 sRGB | 6표본 최소 대비 |
| --- | --- | --- | --- |
| primary | 69,85,108 | 248,250,252 | 7.2486:1 |
| dark | 152,164,178 | 2,6,24 | 7.9554:1 |

모든 표본의 opacity는1이며 조상 opacity·배경 이미지·blend 예외는 없었다. 페이지 가로 넘침·JS예외·POST도0이다. 이는 최종 manual390의 대표 표본 결과다. 모든 글자·이미지 표면·브라우저 대비 인증이나 성능/가독성 개선율은 아니다. 기존 runtime detector의 숫자와 이 계산법을 같은 조건의 전후 개선율로 취급하지 않는다.

## 캡처 상태와 경계

최초 after 다크 통계2프레임은 본문이 충분히 그려지지 않아 판정을 보류했다. 루트가 같은 URL·뷰포트·dark의 새 격리 context에서 fonts.ready,500ms,2RAF 이후 같은 파일을 다시 촬영했다. 검토자는 최종 두 파일을 다시 열어 헤더·본문·스위치 주변의 정상 표현을 읽고 최종 해시를 기록했다. 특정 CSS/테마 제품 결함으로 원인을 단정하지 않고 내부 캡처 과도기의 범위로 남긴다.

스위치 켜짐·URL 이동·팝업 열림·실기기/Safari/스크린리더는 이48장의 추가 판정 범위가 아니다. 해당 동작은 루트의 별도 검증 기록을 따른다. 현재 추가 시각 검토에서 수정이 필요한 우선 문제는 확인하지 못했으며, 기존 브랜드·배치에 취향 변경을 권하지 않는다.
