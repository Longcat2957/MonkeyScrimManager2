# 운영 5페이지 Impeccable 디자인 효과 재평가

2026-11-14. 푸시된 `897eddf34308b45d01dcbab7c848ed09391dce40` 기준이다. 컴포넌트·클래스가 존재하는지를 성공 기준으로 삼지 않고, 수정 전 라이트 10장과 새로 촬영한 20장을 직접 읽어 목적·주요 행동·읽기 순서·밀도·일관성을 비교했다. 새 다크 10장은 현재 상태의 일관성을 확인한 것이며, 다크 수정 전 이미지와 직접 비교했다고 주장하지 않는다. 배경 챔피언 아트의 무작위 차이는 개선 효과에서 제외했다.

결론은 **수동 편성과 경매 준비의 구조 개선은 분명하며, 모든 운영 화면을 같은 정도로 재설계한 것은 아니다**. 모집 요약·대진·결과는 기존에 잘 작동하던 흐름을 유지하면서 제목·안내·조작·상태 표현을 보완했다. 수동 편성은 과업을 완료할 수 있게 되었지만 모바일의 선택 맥락과 작은 해제 버튼 때문에 adapt·polish를 완전히 충분하다고 평가하지 않는다.

실제 URL·DOM·조작 원값은 [workflow.json](workflow.json), 전체 20라우트·UI-01~21·공통 사용처·증거 연결은 [source-inventory.json](source-inventory.json)에 있다. 정적 사용처 연결은 모든 역할에서 동시에 렌더링된다는 뜻이 아니다. 기존 검사 대상 58개 소스의 해시가 모두 일치하며, 작업 목록·기본 80이미지·페이지 소스의 누락은 발견하지 않았다. 이는 디자인 품질의 자동 합격 근거와 구분한다.

- **부분**: 개선은 확인되나 같은 과업에서 남은 마찰이 관찰된다. 기능 자체가 불가능하다는 뜻은 아니다.

## 경매 준비: 첫 발견과 모바일 정보 밀도의 개선이 가장 명확

[수정 전 데스크톱](../before/auction-desktop.png) · [새 데스크톱](workflow/auction-primary-desktop.png) · [수정 전 모바일](../before/auction-mobile.png) · [새 모바일](workflow/auction-primary-mobile.png)

기존 모바일은 후보 목록이 먼저 보이고 경매 준비라는 목표와 저장·시작이 뒤에 있었다. 새 화면은 경매 준비·막힌 이유·저장/시작→팀장 후보와 선택 규칙→팀 설정 순서다. 첫 화면에서 무엇을 해야 하고 왜 아직 시작할 수 없는지 이해할 수 있다. 후보는 검색의 보이는 이름과 한 번의 선택 안내를 가진다.

팀 카드가 모바일에서도 2×2라 네 팀의 상태와 포인트를 비교하기 쉬워졌다. 기존 세로 네 장의 긴 빈 공간은 줄었고 후보 목록은 자체 스크롤로 관리된다. 제목·팀 이름·입력 레이블·숫자가 층위별로 구별된다. 팀장 미지정은 점선 자리로, 후보 선택은 상태 변화로 알려 주므로 색만으로 판단하게 하지 않는다.

현재 준비 상태에서는 저장·시작이 비활성이며 후보를 선택했다가 해제하면 다시 같은 상태가 된다. 시작 포인트4개는 모두1000을 유지했다. 저장·시작 API나 입찰 규칙을 바꾸지 않았다. 이 기본 상태에서 layout·clarify·adapt·quieter의 효과는 충분하다. 진행 경매의 입찰과 후보 팝업은 이 새 기본 이미지20조건에서 다시 실행한 범위가 아니다.

데스크톱의 팀→준결승→결승과 모바일의 같은 순서 세로 흐름은 원래 장점이며 유지됐다. 새로 커진 대진 제목과 0/4 배치, 배치할 팀이라는 이름, 팀을 고른 뒤 빈 자리를 누르라는 한 줄이 시작점을 더 명확하게 만든다. 빈 자리와 아직 정해지지 않은 결승 참가자를 분리한 표현도 유지된다.

기존에는 대진·확정이라는 작은 표현이 결과 화면에서도 남았다. 새 대진 결과 제목은 편집 준비 화면과 현재 목적을 구분한다. 확정 배지를 덜어 낸 것은 distill·quieter의 실제 효과다. 준결승2:0·1:2와 결승3:2는 같은 위치의 숫자와 승 문구·바탕색으로 읽힌다. 색만 보고 승패를 추론하지 않아도 된다.

## 검증 범위와 보류한 판단

- 실제 Playwright MCP로 5URL×1440×1000·390×844×primary/dark=20조건을 새로 촬영했고20장을 모두 읽었다. 라이트 수정 전10장과 추가 선택 맥락1장도 읽었다.
